# Script template (explainer arc, ~2 min, ~300 words)

This shows the *form* of a tight explainer script: one idea per line, a slam word, micro-pauses, an arc. The example column comes from a learning exercise and follows a studied reference closely, so **don't reuse it for a published film**. Write an original script with your own arc, lines and argument order; keep only the rhythm rules.

One line = one beat. Use `/` for a micro-pause and CAPS for the slam word.

| # | section | pattern | example (from a film about directing Claude for motion) |
|---|---|---|---|
| 1 | HOOK | bold claim about this very video | This video was made by AI. |
| 2 | HOOK | "everyone asks the same thing" | And everyone's asking the same thing... what's the prompt? |
| 3 | HOOK | slam the counter-claim | WRONG question. |
| 4 | PROBLEM | the quiet truth | Because Claude didn't make this alone. |
| 5 | PROBLEM | naive ask → bad result | Ask it for a "cool motion video"... and you get slop. |
| 6 | REVEAL | the difference / the who | The difference? / A director. |
| 7 | REVEAL | name slam | His name's Iksan. / Iksan Dwee Saputra. |
| 8 | REVEAL | what they did | And he turned his motion taste into a formula Claude can read. |
| 9 | REVEAL | punchy contrast | Same AI. / Different director. |
| 10 | META | self-reference | And this video you're watching right now? Made with that exact formula. |
| 11 | PROOF | what it means for the viewer | Which means Claude can make motion at this level... for ANY theme. |
| 12 | PROOF | real numbers only | He fed it two hundred and fifty megabytes of official motion docs. Sixty-six expert notes. |
| 13 | META | "this is already the tutorial" | And this video? / It's already the TUTORIAL. |
| 14 | EPIC | one-beat turn | So... / let's cook. |
| 15 | CALM | slow, thin type | But first, / one thing you need to know. Because without it, / none of this works for you. |
| 16 | CORE | myth busting | There is no magic prompt. / There NEVER was. |
| 17 | CORE | what it really is | What Iksan built is better: / a motion brain. |
| 18 | CORE | escalation | And honestly, it's not just a prompt. / It's a full LIBRARY. |
| 19 | CORE | the thesis | Because the docs / ARE the skill. |
| 20 | CORE | scope | Twelve categories that teach Claude to think like a real motion designer, / and editor. |
| 21 | CORE | list (truck shot) | Choreography. Physics. Shaders. Typography. Sound. Rendering. |
| 22 | CORE | summary slam | Not a prompt. / A whole STUDIO, in one folder. |
| 23 | CORE | secret | Here's the part nobody tells you. |
| 24 | CORE | effort | To build this, Iksan directed every detail himself. |
| 25 | CORE | triple | Every library. / Every RULE. / Every FIX. |
| 26 | CORE | concrete notes | Make it smoother. / Lower that whoosh. / Hold the ending one beat LONGER. |
| 27 | YOU | it's all inside | Now all of that lives INSIDE the formula. |
| 28 | YOU | framework | The formula is the framework. / It does the heavy lifting. |
| 29 | YOU | turn to viewer | The rest? / That's YOU. |
| 30 | YOU | your part | Your idea. / Your taste. / Your theme. |
| 31 | YOU | breadth montage | Football. Fashion. Science. Food. / Anything. |
| 32 | CTA | relief | He did the hard part, / so you don't have to. |
| 33 | CTA | keyword | Comment MOTION, / and follow for part two. |

The TTS text file is the same lines, one per line, with phonetic spellings and no table. Section turns that need a longer breath go into `vo_rules.json` → `long_before_line` (0-based line index).
