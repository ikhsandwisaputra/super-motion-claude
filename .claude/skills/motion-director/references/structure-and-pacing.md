# Default structure, pacing and storyboard

Measured from one 2-minute reference explainer during a study. Treat it as ONE proven template among many. The pacing numbers (words/s, beat length, hits after pauses) transfer well. The arc and colour script are this reference's expression: design your own per concept (problem→solution, myth→truth, before→after, list, story).

## Arc (percent of runtime)
| % | section | job | typical visuals |
|---|---|---|---|
| 0–7 | HOOK | bold claim, then "everyone asks the same thing", then slam the counter-claim | colour strobe in the first 0.5 s, per-letter chromatic smear, background swaps orange → red on the slam |
| 7–13 | PROBLEM | a quiet line, then "ask for X → you get <bad result>" | glitch to black; one line with a red marker per word; card ribbon of bad results |
| 13–30 | REVEAL + PROOF | who/what; a name slam; social proof or real numbers | voxel sets, push into a monitor, counters, pull-out reveal |
| 30–38 | META TURN + CONTRAST | "this very video is the tutorial"; one epic beat; then a calm monochrome passage | PiP shrink + rewind montage; storm + lightning; galaxy/planet/moon, thin type, no red |
| 38–80 | CORE VALUE | "there is no magic X"; what is inside; a pipeline of steps; "every rule, every fix" | stage set, icon tiles on a lateral truck, editor-timeline UI |
| 80–90 | YOU | everything goes into the file; the framework does most of it; "that's YOU" | elements fly into a file, framework panel, smash zoom into the hero |
| 90–100 | CTA | "did the hard part so you don't have to"; comment keyword + teaser | blurred set, hero points at an input bar that types the keyword, toast slides in; near-static camera; hold 5–8 s |

## Pacing
- One VO phrase per beat. Median beat ~1.5 s (range 0.2–4 s), with 2–3 long "system" shots of 6–11 s carried by camera travel.
- A visual event every 0.3–0.5 s, roughly every spoken word. Never 15 frames with nothing new, except the CTA hold.
- Big hits (slam, mosaic, smash zoom, flash) land 0–5 frames after a VO pause, on the first syllable of a phrase. They never land mid-word or on a phrase's last word.
- Leave 0.3–0.45 s of silence before section punchlines. The edited VO and the bed drop together.
- Pacing data: ~2.5 words/s; VO pauses 1–8 frames inside phrases.

## Transition mix (whole film)
Hard cut on a phrase start ≈ 50% · pixel mosaic ≈ 20–25% (full 12–14 f, or partial 3–5 f for angle changes in one set) · flash/white-out ≈ 12% · glitch to black ≈ 8–10% · specials (whip→mosaic, PiP shrink, smash zoom, foreground wipe, halftone wipe, light sweep) at section turns. The calm section uses short crossfades only.

## Colour script
orange → red → black → warm voxel interiors → night/blue storm → monochrome cosmos → red-carpet stage → black + teal grid → teal/yellow "you" → CTA dark + teal. Red = conflict/emphasis. Teal = data/UI/CTA. Yellow/amber = ideas, light.
