# Originality: learn from references, never copy them

References are study material. A finished film must be the client's own: own idea, own world, own motion language. The goal is to understand why a reference works and transfer the craft, not reproduce the piece.

## Transferable craft (learn it and reuse it freely)
These are general techniques that no one owns:
- Syncing every on-screen word to its spoken word, and landing hits after VO pauses.
- Type living in 3D, with a camera that travels between phrases and finished phrases that recede.
- Word roles (connector / content / emphasis) driving size, font and entrance.
- Damped springs, expo/quint eases, overlap, holds before hits, faster exits.
- Real motion blur, soft grading, DOF focus pulls.
- VO-first mixing, beds that drop out before punchlines, one SFX per event with pitch variation.
- Pacing ideas: tempo contrast with a calm section before the core message, a near-static CTA.

## Expression (do not copy)
These belong to the reference's creator:
- The script: its lines, jokes, hooks and the order of its arguments.
- Characters and mascots, their poses and props.
- The visual world: a specific set (the same rooms, props and stage), a recognisable palette/colour script, logos and UI the creator designed.
- The signature combination that makes the piece recognisable. For the studied reference that combination is a pixel detective + voxel dioramas + red/white/black mosaic + orange→red slam.
- The shot-by-shot sequence. If a viewer could put both videos side by side and match scenes one to one, it is a copy.

## How to make each film original
1. **Concept first.** What is this film's own idea and metaphor, derived from the topic/brand? (A lab brand suggests diffusion, particles and liquid; a logistics brand suggests routes, flows and grids.)
2. **Own visual world.** Choose a new palette, a new character style (or none), new sets or backgrounds, and a new texture. Using the engine's default pixel/voxel look as-is repeats the study piece; change it.
3. **Own motion language.** Pick 2–3 signature eases, one hero transition chosen from the arsenal (liquid wipe, gooey morph, page curl, light leak, shape mask…) and a stagger rule.
4. **Own structure.** Pick an arc that serves the message (problem→solution, myth→truth, before→after, list, story). Reference percentages are only one data point.
5. **Similarity check before showing anyone.** Compare your overview sheet with the reference overview. No scene, layout or line should map one to one. If one does, redesign it.

## Recreating a reference 1:1
Only as a private exercise, clearly labelled, never published, never sent to a client, and never shared outside the learning context. If someone asks to publish a near-copy, say so plainly and propose an original version.
