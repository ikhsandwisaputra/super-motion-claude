# UI Scenes

> UI Scenes are deprecated. Use Hana, Spline's 2D canvas, for interfaces and animated graphics.



<Callout type="warn">
  **UI Scenes are deprecated.** The feature never left beta and is no longer
  documented. Build interfaces and animated graphics in **Hana**, Spline's 2D
  canvas, instead.
</Callout>

Hana covers what UI Scenes were for — 2D layout, typography, effects, states and
interactivity — as a full editor rather than a beta panel, with its own
publishing pipeline.
