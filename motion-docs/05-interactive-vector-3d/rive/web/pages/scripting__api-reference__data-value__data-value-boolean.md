# DataValueBoolean

[DataValue](/docs/scripting/api-reference/data-value/data-value) that stores a boolean value.

## Fields

### `value`

The stored boolean value.

```lua theme={null}
local dv: DataValueBoolean = DataValue.boolean()
dv.value = false
```
