# DataValueNumber

[DataValue](/docs/scripting/api-reference/data-value/data-value) that stores a number value.

## Fields

### `value`

The stored numeric value.

```lua theme={null}
local dv: DataValueNumber = DataValue.number()
dv.value = 200
```
