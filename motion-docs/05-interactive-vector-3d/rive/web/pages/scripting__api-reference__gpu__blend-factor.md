# BlendFactor

Blend factor for src/dst color and alpha (WebGPU canonical strings).

* `zero`
* `one`
* `src`
* `one-minus-src`
* `src-alpha`
* `one-minus-src-alpha`
* `dst`
* `one-minus-dst`
* `dst-alpha`
* `one-minus-dst-alpha`
* `src-alpha-saturated`
* `constant`
* `one-minus-constant`
