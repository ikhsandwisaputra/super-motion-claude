# DataValueString

[DataValue](/docs/scripting/api-reference/data-value/data-value) that stores a string value.

## Fields

### `value`

The stored string value.

```lua theme={null}
local dv: DataValueString = DataValue.string()
dv.value = "I heart Rive."
```
