# PointerType

The type of event.

* `pointerEnter`
* `pointerExit`
* `pointerDown`
* `pointerUp`
* `pointerMove`
* `click`
* `pointerDrag`
* `unknown`

Used in [PointerEvent](/docs/scripting/api-reference/artboards/pointer-event).
