# FormatScope

Highlight scope for a token. Scopes map onto the same theme colors used by
the Luau and WGSL editors.

* `none`
* `keyword`
* `type`
* `literal`
* `number`
* `operator`
* `punctuation`
* `property`
* `string`
* `comment`
* `boolean`
* `nil`
* `interp`
* `function`
