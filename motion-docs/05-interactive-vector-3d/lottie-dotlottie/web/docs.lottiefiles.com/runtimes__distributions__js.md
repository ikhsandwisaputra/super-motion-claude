# JavaScript Player
Documentation for @lottiefiles/dotlottie-web, the core JavaScript player for rendering .lottie and Lottie JSON animations in the browser.

The dotLottie JavaScript player (`@lottiefiles/dotlottie-web`) renders `.lottie` and Lottie JSON animations in any browser, with no framework dependency. It gives you full control over playback, layout, theming, multi-animation files, and interactive state machines. Dedicated wrapper packages are available for React, Vue, Svelte, and Web Components.
