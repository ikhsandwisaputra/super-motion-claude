# Advanced Graph Editor
The Advanced Graph Editor is a native feature within Lottie Creator that gives motion designers frame-level control over animation curves, easing, and property timing — without ever leaving the browser. It mirrors the keyframe curve editing experience of After Effects, but lives natively in a web-first, Lottie-native workflow.

<Callout type="info" icon={false}>
  The Advanced Graph Editor extends the [Easing](/en/creator/07_animation/easing) controls with a full curve-editing
  surface for advanced timing work.
</Callout>

## What the Advanced Graph Editor Does

<List type="bullet">
  <ListItem>**Frame-level control** — adjust animation curves precisely across the timeline</ListItem>
  <ListItem>**Curve editing** — shape acceleration and deceleration visually with bezier handles</ListItem>
  <ListItem>**Easing refinement** — fine-tune in and out tangents per keyframe</ListItem>
  <ListItem>**Property timing** — control how values change over time for any animated property</ListItem>
</List>
