# Motion System
Motion System is a design system for motion. With it, you can create a set of reusable motion patterns and apply them to your animations, ensuring consistency and efficiency across your animations.

## Motion System in LottieFiles Platform

Motion Systems are created and managed in the LottieFiles Platform.

If this is your first time using Motion Systems, you will see a button to create your first motion system.

From there, you can create and manage Sections. Sections are a collection of elements that can be applied to your animations. They include the following elements:

- Colors
- Easings
- Fonts
- Motion Presets
- Assets, including images and Lottie animations

As well as Documentation for notes and guidelines.

## Motion System in LottieFiles Creator

Motion Systems can be used in Creator via the Motion System plugin. If you don't have a Motion System, you can click the button to take you to the LottieFiles Platform to create one.

The rest of the sections work in a similar way. However, Motion Presets cannot be created in the LottieFiles Platform and instead need to be created in Creator via the Motion Presets plugin.
