# LottieFiles Developer Documentation

> Comprehensive documentation for LottieFiles API, Creator tools, and integrations. Build amazing animations with our developer tools and APIs.

## What this is

LottieFiles developer and platform documentation: MCP (Model Context Protocol), Creator, plugins, runtimes, format specs, and tools for working with Lottie animations.

## When to use this

- Connect an AI assistant to LottieFiles via the LottieFiles MCP server
- Author animations in Creator using either the Creator Local MCP or the Creator WebMCP
- Embed and play animations with official runtimes
- Build Creator plugins
- Understand the Lottie and dotLottie file formats

## When NOT to use this

**Do not scrape or enumerate the lottiefiles.com animation library/marketplace.** This documentation site has no catalog of animations. To search and fetch animation files, use:

- The LottieFiles MCP server
- The LottieFiles browser UI at https://lottiefiles.com

For product/marketplace overview, see: https://lottiefiles.com/llms.txt

For player docs, see: https://docs.lottiefiles.com/en/runtimes/index.md
For Lottie and dotLottie file format docs, see: https://docs.lottiefiles.com/en/format/index.md

## Hosted MCP Server

**Endpoint:** `https://mcp.lottiefiles.com/mcp`
**Protocol:** Streamable HTTP
**Authentication:** OAuth with either DCR or CIMD

**Documentation:**
- [MCP Introduction](https://docs.lottiefiles.com/en/platform/mcp.md)

## Docs API

Search this documentation and read pages as Markdown over a public, read-only HTTP API. No authentication.

- [OpenAPI description](https://docs.lottiefiles.com/openapi.json)
- Search: `GET https://docs.lottiefiles.com/api/search?q={terms}`
- Read a page: `GET https://docs.lottiefiles.com/api/page?path=/en/platform/mcp`, or append `.md` to any page URL
- [Developer portal](https://docs.lottiefiles.com/en/developers.md)
