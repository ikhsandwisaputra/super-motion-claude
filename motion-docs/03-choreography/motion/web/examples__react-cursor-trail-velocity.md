### Introduction

The Cursor trail velocity example shows how to spawn images as the user's cursor moves around the screen.

This example is a twist on the [original Cursor trail](https://motion.dev/examples/react-cursor-trail) example, where the pointer velocity is recorded at the moment of image spawn and this is fed into a `type: "inertia"` animation.
