# @theatre/dataverse

* [Theatre.js Docs](https://www.theatrejs.com/docs/latest)
* [API Reference](https://www.theatrejs.com/docs/latest/api)
* @theatre/dataverse

Dataverse is the reactive dataflow library
[Theatre.js](https://www.theatrejs.com) is built on. It is inspired by ideas in
[functional reactive programming](https://en.wikipedia.org/wiki/Functional_reactive_programming)
and it is optimised for interactivity and animation.

Documentation is available on [Github](https://github.com/theatre-js/theatre/tree/main/packages/dataverse).
