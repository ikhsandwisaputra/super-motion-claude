# [scrambleText parameters](https://animejs.com/documentation/text/scrambletext/scrambletext-parameters "scrambleText parameters")

Configures the scramble text animation behaviour.

```js
animate(target, {
  innerHTML: scrambleText({
  ┌──────────────────────────┐
  │ text: 'Hello World',     │
  │ chars: 'uppercase',      │
  │ from: 'center',          │
  │ cursor: '_',             ├─ Parameters
  │ settleDuration: 500,     │
  │ revealRate: 60,          │
  │ settleRate: 30,          │
  └──────────────────────────┘
  }),
});
```
