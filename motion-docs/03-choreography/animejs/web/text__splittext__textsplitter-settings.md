# [TextSplitter settings](https://animejs.com/documentation/text/splittext/textsplitter-settings "TextSplitter settings")

Configures how text within the target HTML element should be split.

```js
splitText(target, {
┌────────────────────────┐
│ lines: true,           ├─ Settings
│ words: {               │
│   wrap: 'clip',        │
│   class: 'split-word', │
│   clone: true          │
│ },                     │
│ includeSpaces: true,   │
│ debug: true,           │
└────────────────────────┘
});
```
