# [Timer playback settings](https://animejs.com/documentation/timer/timer-playback-settings "Timer playback settings")

Specify the timings and behaviours of a timer.
Playback settings properties are defined directly in the `createTimer()` parameters `Object`.

```js
createTimer({
┌───────────────────┐
│ duration: 1000,   │
│ frameRate: true,  ├─ Playback Settings
│ loop: true,       │
└───────────────────┘
  onBegin: () => {},
  onLoop: () => {},
  onUpdate: () => {},
});
```
