A class to describe a print stream.

Each `p5.PrintWriter` object provides a way to save a sequence of text data, called the print stream, to the user's computer. It's a low-level object that enables precise control of text output. Functions such as [saveStrings()](https://p5js.org/reference/p5/saveStrings/) and [saveJSON()](https://p5js.org/reference/p5/saveJSON/) are easier to use for simple file saving.

Note: [createWriter()](https://p5js.org/reference/p5/createWriter/) is the recommended way to make an instance of this class.

## Examples

## Syntax

`p5.PrintWriter(filename, [extension])`

## Parameters

filename

String: name of the file to create.

extension

String: format to use for the file.

// Save the file when the user double-clicks.
function doubleClicked() {
  // Create a p5.PrintWriter object.
  let myWriter = createWriter('xo.txt');

  // Add some lines to the print stream.
  myWriter.print('XOO');
  myWriter.print('OXO');
  myWriter.print('OOX');

  // Save the file and close the print stream.
  myWriter.close();
}
