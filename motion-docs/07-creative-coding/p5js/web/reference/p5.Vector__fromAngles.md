Creates a new 3D vector from a pair of ISO spherical angles.

## Examples

## Syntax

`fromAngles(theta, phi, [length])`

## Parameters

theta

Number: polar angle in radians (zero is up).

phi

Number: azimuthal angle in radians (zero is out of the screen).

length

Number: length of the new vector (defaults to 1).

## Returns

p5.Vector: new [p5.Vector](https://p5js.org/reference/p5/p5.Vector/) object.

function setup() {
  createCanvas(100, 100, WEBGL);

  describe('A light shines on a pink sphere as it orbits.');
}

function draw() {
  background(0);

  // Calculate the ISO angles.
  let theta = frameCount *  0.05;
  let phi = 0;

  // Create a p5.Vector object.
  let v = p5.Vector.fromAngles(theta, phi, 100);

  // Create a point light using the p5.Vector.
  let c = color('deeppink');
  pointLight(c, v);

  // Style the sphere.
  fill(255);
  noStroke();

  // Draw the sphere.
  sphere(35);
}
