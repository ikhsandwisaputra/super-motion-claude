Calculates the magnitude (length) of the vector.

Use [mag()](https://p5js.org/reference/p5/mag/) to calculate the magnitude of a 2D vector using components as in `mag(x, y)`.

## Examples

## Syntax

`mag()`

## Parameters

## Returns

Number: magnitude of the vector.

## Example code (extracted)

```js
function setup() {
  createCanvas(100, 100);

  background(200);

  // Create a p5.Vector object.
  let p = createVector(30, 40);

  // Draw a line from the origin.
  line(0, 0, p.x, p.y);

  // Style the text.
  textAlign(CENTER);
  textSize(16);

  // Display the vector's magnitude.
  let m = p.mag();
  text(m, p.x, p.y);

  describe('A diagonal black line extends from the top left corner of a gray square. The number 50 is written at the end of the line.');
}
```
