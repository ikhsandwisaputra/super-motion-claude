Stops drawing shapes to the framebuffer.

[myBuffer.begin()](https://p5js.org/reference/p5.Framebuffer/begin/) and `myBuffer.end()` allow shapes to be drawn to the framebuffer. [myBuffer.begin()](https://p5js.org/reference/p5.Framebuffer/begin/) begins drawing to the framebuffer and `myBuffer.end()` stops drawing to the framebuffer. Changes won't be visible until the framebuffer is displayed as an image or texture.

## Example code (extracted)

```js
let myBuffer;

function setup() {
  createCanvas(100, 100, WEBGL);

  // Create a p5.Framebuffer object.
  myBuffer = createFramebuffer();

  describe('An empty gray canvas. The canvas gets darker and a rotating, multicolor torus appears while the user presses and holds the mouse.');
}

function draw() {
  background(200);

  // Start drawing to the p5.Framebuffer object.
  myBuffer.begin();

  background(50);
  rotateY(frameCount * 0.01);
  normalMaterial();
  torus(30);

  // Stop drawing to the p5.Framebuffer object.
  myBuffer.end();

  // Display the p5.Framebuffer object while
  // the user presses the mouse.
  if (mouseIsPressed === true) {
    image(myBuffer, -50, -50);
  }
}
```
