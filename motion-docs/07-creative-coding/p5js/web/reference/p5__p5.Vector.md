A class to describe a two or three-dimensional vector.

A vector can be thought of in different ways. In one view, a vector is like an arrow pointing in space. Vectors have both magnitude (length) and direction.

`p5.Vector` objects are often used to program motion because they simplify the math. For example, a moving ball has a position and a velocity. Position describes where the ball is in space. The ball's position vector extends from the origin to the ball's center. Velocity describes the ball's speed and the direction it's moving. If the ball is moving straight up, its velocity vector points straight up. Adding the ball's velocity vector to its position vector moves it, as in `pos.add(vel)`. Vector math relies on methods inside the `p5.Vector` class.

Note: [createVector()](https://p5js.org/reference/p5/createVector/) is the recommended way to make an instance of this class.

## Examples

## Syntax

`p5.Vector([x], [y], [z])`

## Parameters

x

Number: x component of the vector.

y

Number: y component of the vector.

z

Number: z component of the vector.

## Methods

[getValue](https://p5js.org/reference/p5.Vector/getValue)

Retrieves the value at the specified index from the vector.

This method allows you to get the value of a specific component of the vector by providing its index. Think of the vector as a list of numbers, where each number represents a different direction (like x, y, or z). The index is just the position of the number in that list.

For example, if you have a vector with values 10, 20, 30 the index 0 would give you the first value 10, index 1 would give you the second value 20, and so on.

[setValue](https://p5js.org/reference/p5.Vector/setValue)

Sets the value at the specified index of the vector.

This method allows you to change a specific component of the vector by providing its index and the new value you want to set. Think of the vector as a list of numbers, where each number represents a different direction (like x, y, or z). The index is just the position of the number in that list.

For example, if you have a vector with values [0, 20, 30], and you want to change the second value (20) to 50, you would use this method with index 1 (since indexes start at 0) and value 50.

[toString](https://p5js.org/reference/p5.Vector/toString)

Returns a string representation of a vector.

Calling `toString()` is useful for printing vectors to the console while debugging.

[set](https://p5js.org/reference/p5.Vector/set)

Sets the the vector to a new value.

`set()` can use separate numbers, as in `v.set(1, 2, 3)`, a [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.set(v2)`, or an array of numbers, as in `v.set([1, 2, 3])`.

[copy](https://p5js.org/reference/p5.Vector/copy)

Returns a copy of the [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object.

[add](https://p5js.org/reference/p5.Vector/add)

Adds to a vector's components.

`add()` can use separate numbers, as in `v.add(1, 2, 3)`, another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.add(v2)`, or an array of numbers, as in `v.add([1, 2, 3])`.

You should add vectors only when they are the same size. When two vectors of different sizes are added, the smaller dimension will be used, any additional values of the longer vector will be ignored. For example, adding `[1, 2, 3]` and `[4, 5]` will result in `[5, 7]`.

Calling `add()` with no arguments, as in `v.add()`, has no effect.

This method supports N-dimensional vectors.

The static version of `add()`, as in `p5.Vector.add(v2, v1)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the originals.

[rem](https://p5js.org/reference/p5.Vector/rem)

Performs modulo (remainder) division with a vector's components.

`rem()` can use separate numbers, as in `v.rem(1, 2, 3)`, another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.rem(v2)`, or an array of numbers, as in `v.rem([1, 2, 3])`.

If only one value is provided, as in `v.rem(2)`, then all the components will be set to their values modulo 2. Calling `rem()` with no arguments, as in `v.rem()`, has no effect.

You should modulo vectors only when they are the same size. When two vectors of different sizes are used, the smaller dimension will be used, any additional values of the longer vector will be ignored. For example, taking `[3, 6, 9]` modulo `[2, 4]` will result in `[1, 2]`.

The static version of `rem()`, as in `p5.Vector.rem(v2, v1)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the originals.

[sub](https://p5js.org/reference/p5.Vector/sub)

Subtracts from a vector's components.

`sub()` can use separate numbers, as in `v.sub(1, 2, 3)`, another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.sub(v2)`, or an array of numbers, as in `v.sub([1, 2, 3])`.

Calling `sub()` with no arguments, as in `v.sub()`, has no effect.

You should subtract vectors only when they are the same size. When two vectors of different sizes are used, the smaller dimension will be used, any additional values of the longer vector will be ignored. For example, subtracting `[1, 2]` from `[3, 5, 7]` will result in `[2, 3]`.

The static version of `sub()`, as in `p5.Vector.sub(v2, v1)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the originals.

[mult](https://p5js.org/reference/p5.Vector/mult)

Multiplies a vector's components.

`mult()` can use separate numbers, as in `v.mult(1, 2, 3)`, another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.mult(v2)`, or an array of numbers, as in `v.mult([1, 2, 3])`.

If only one value is provided, as in `v.mult(2)`, then all the components will be multiplied by 2. Calling `mult()` with no arguments, as in `v.mult()`, has no effect.

You should multiply vectors only when they are the same size. When two vectors of different sizes are multiplied, the smaller dimension will be used, any additional values of the longer vector will be ignored. For example, multiplying `[1, 2, 3]` by `[4, 5]` will result in `[4, 10]`.

The static version of `mult()`, as in `p5.Vector.mult(v, 2)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the originals.

[div](https://p5js.org/reference/p5.Vector/div)

Divides a vector's components.

`div()` can use separate numbers, as in `v.div(1, 2, 3)`, another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object, as in `v.div(v2)`, or an array of numbers, as in `v.div([1, 2, 3])`.

If only one value is provided, as in `v.div(2)`, then all the components will be divided by 2. Calling `div()` with no arguments, as in `v.div()`, has no effect.

You should divide vectors only when they are the same size. When two vectors of different sizes are divided, the smaller dimension will be used, any additional values of the longer vector will be ignored. For example, dividing `[8, 12, 21]` by `[2, 3]` will result in `[4, 4]`.

The static version of `div()`, as in `p5.Vector.div(v, 2)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the originals.

[mag](https://p5js.org/reference/p5.Vector/mag)

Calculates the magnitude (length) of the vector.

Use [mag()](https://p5js.org/reference/p5/mag/) to calculate the magnitude of a 2D vector using components as in `mag(x, y)`.

[magSq](https://p5js.org/reference/p5.Vector/magSq)

Calculates the magnitude (length) of the vector squared.

[dot](https://p5js.org/reference/p5.Vector/dot)

Calculates the dot product of two vectors.

The dot product is a number that describes the overlap between two vectors. Visually, the dot product can be thought of as the "shadow" one vector casts on another. The dot product's magnitude is largest when two vectors point in the same or opposite directions. Its magnitude is 0 when two vectors form a right angle.

The version of `dot()` with one parameter interprets it as another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object.

The version of `dot()` with multiple parameters interprets them as the `x`, `y`, and `z` components of another vector.

The static version of `dot()`, as in `p5.Vector.dot(v1, v2)`, is the same as calling `v1.dot(v2)`.

[cross](https://p5js.org/reference/p5.Vector/cross)

Calculates the cross product of two vectors.

The cross product is a vector that points straight out of the plane created by two vectors. The cross product's magnitude is the area of the parallelogram formed by the original two vectors.

The cross product is defined on 3-dimensional vectors, and will use the `x`, `y`, and `z` components. This method should only be used with 3D vectors.

The static version of `cross()`, as in `p5.Vector.cross(v1, v2)`, is the same as calling `v1.cross(v2)`.

[dist](https://p5js.org/reference/p5.Vector/dist)

Calculates the distance between two points represented by vectors.

A point's coordinates can be represented by the components of a vector that extends from the origin to the point.

The static version of `dist()`, as in `p5.Vector.dist(v1, v2)`, is the same as calling `v1.dist(v2)`.

Use [dist()](https://p5js.org/reference/p5/dist/) to calculate the distance between points using coordinates as in `dist(x1, y1, x2, y2)`.

[normalize](https://p5js.org/reference/p5.Vector/normalize)

Scales the components of a [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object so that its magnitude is 1.

The static version of `normalize()`, as in `p5.Vector.normalize(v)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[limit](https://p5js.org/reference/p5.Vector/limit)

Limits a vector's magnitude to a maximum value.

The static version of `limit()`, as in `p5.Vector.limit(v, 5)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[setMag](https://p5js.org/reference/p5.Vector/setMag)

Sets a vector's magnitude to a given value.

The static version of `setMag()`, as in `p5.Vector.setMag(v, 10)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[heading](https://p5js.org/reference/p5.Vector/heading)

Calculates the angle a 2D vector makes with the positive x-axis.

By convention, the positive x-axis has an angle of 0. Angles increase in the clockwise direction.

If the vector was created with [createVector()](https://p5js.org/reference/p5/createVector/), `heading()` returns angles in the units of the current [angleMode()](https://p5js.org/reference/p5/angleMode/).

The static version of `heading()`, as in `p5.Vector.heading(v)`, works the same way.

[setHeading](https://p5js.org/reference/p5.Vector/setHeading)

Rotates a 2D vector to a specific angle without changing its magnitude.

By convention, the positive x-axis has an angle of 0. Angles increase in the clockwise direction.

If the vector was created with [createVector()](https://p5js.org/reference/p5/createVector/), `setHeading()` uses the units of the current [angleMode()](https://p5js.org/reference/p5/angleMode/).

[rotate](https://p5js.org/reference/p5.Vector/rotate)

Rotates a 2D vector by an angle without changing its magnitude.

By convention, the positive x-axis has an angle of 0. Angles increase in the clockwise direction.

If the vector was created with [createVector()](https://p5js.org/reference/p5/createVector/), `rotate()` uses the units of the current [angleMode()](https://p5js.org/reference/p5/angleMode/).

The static version of `rotate()`, as in `p5.Vector.rotate(v, PI)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[angleBetween](https://p5js.org/reference/p5.Vector/angleBetween)

Calculates the angle between two vectors.

The angles returned are signed, which means that `v1.angleBetween(v2) === -v2.angleBetween(v1)`.

If the vector was created with [createVector()](https://p5js.org/reference/p5/createVector/), `angleBetween()` returns angles in the units of the current [angleMode()](https://p5js.org/reference/p5/angleMode/).

[lerp](https://p5js.org/reference/p5.Vector/lerp)

Calculates new `x`, `y`, and `z` components that are proportionally the same distance between two vectors.

The `amt` parameter is the amount to interpolate between the old vector and the new vector. 0.0 keeps all components equal to the old vector's, 0.5 is halfway between, and 1.0 sets all components equal to the new vector's.

The static version of `lerp()`, as in `p5.Vector.lerp(v0, v1, 0.5)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[slerp](https://p5js.org/reference/p5.Vector/slerp)

Calculates a new heading and magnitude that are between two vectors.

The `amt` parameter is the amount to interpolate between the old vector and the new vector. 0.0 keeps the heading and magnitude equal to the old vector's, 0.5 sets them halfway between, and 1.0 sets the heading and magnitude equal to the new vector's.

`slerp()` differs from [lerp()](https://p5js.org/reference/p5.Vector/lerp/) because it interpolates magnitude. Calling `v0.slerp(v1, 0.5)` sets `v0`'s magnitude to a value halfway between its original magnitude and `v1`'s. Calling `v0.lerp(v1, 0.5)` makes no such guarantee.

The static version of `slerp()`, as in `p5.Vector.slerp(v0, v1, 0.5)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[reflect](https://p5js.org/reference/p5.Vector/reflect)

Reflects a vector about a line in 2D or a plane in 3D.

The orientation of the line or plane is described by a normal vector that points away from the shape.

The static version of `reflect()`, as in `p5.Vector.reflect(v, n)`, returns a new [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object and doesn't change the original.

[array](https://p5js.org/reference/p5.Vector/array)

Returns the vector's components as an array of numbers.

[equals](https://p5js.org/reference/p5.Vector/equals)

Checks whether all the vector's components are equal to another vector's.

`equals()` returns `true` if the vector's components are all the same as another vector's and `false` if not.

The version of `equals()` with one parameter interprets it as another [p5.Vector](https://p5js.org/reference/p5/p5.Vector) object.

The version of `equals()` with multiple parameters interprets them as the components of another vector. Any missing parameters are assigned the value 0.

The static version of `equals()`, as in `p5.Vector.equals(v0, v1)`, interprets both parameters as [p5.Vector](https://p5js.org/reference/p5/p5.Vector) objects.

[clampToZero](https://p5js.org/reference/p5.Vector/clampToZero)

Replaces the components of a [p5.Vector](https://p5js.org/reference/p5/p5.Vector) that are very close to zero with zero.

In computers, handling numbers with decimals can give slightly imprecise answers due to the way those numbers are represented. This can make it hard to check if a number is zero, as it may be close but not exactly zero. This method rounds very close numbers to zero to make those checks easier

https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global\_Objects/Number/EPSILON

[fromAngle](https://p5js.org/reference/p5.Vector/fromAngle)

Creates a new 2D vector from an angle.

[fromAngles](https://p5js.org/reference/p5.Vector/fromAngles)

Creates a new 3D vector from a pair of ISO spherical angles.

[random2D](https://p5js.org/reference/p5.Vector/random2D)

Creates a new 2D unit vector with a random heading.

[random3D](https://p5js.org/reference/p5.Vector/random3D)

```js
let pos;
let vel;

function setup() {
  createCanvas(100, 100);

  // Create p5.Vector objects.
  pos = createVector(50, 100);
  vel = createVector(0, -1);

  describe('A black dot moves from bottom to top on a gray square. The dot reappears at the bottom when it reaches the top.');
}

function draw() {
  background(200);

  // Add velocity to position.
  pos.add(vel);

  // If the dot reaches the top of the canvas,
  // restart from the bottom.
  if (pos.y < 0) {
    pos.y = 100;
  }

  // Draw the dot.
  strokeWeight(5);
  point(pos);
}
```
