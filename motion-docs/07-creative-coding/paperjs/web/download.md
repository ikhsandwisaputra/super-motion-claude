# Download

The recommended way to install and maintain Paper.js as a dependency in your project is through [NPM](https://www.npmjs.com/):

```
npm install paper
```

Read more detailed installation instructions in our [README file](https://github.com/paperjs/paper.js/blob/develop/README.md) on Github.

[Release versions](https://paperjs.org/download/#release-versions) are also offered as packaged ZIP files below.
Alternatively, you can download the latest [prebuilt development versions](https://paperjs.org/download/#development-builds).

## Development Builds

There are three ways to work with the latest development version in the [develop](https://github.com/paperjs/paper.js/tree/develop) branch, the first two relying on automatic prebuilding after each commit:

* Point NPM or Bower to specific commits in the [prebuilt/module](https://github.com/paperjs/paper.js/tree/prebuilt/module) branch
* Download the latest packaged ZIP file from the [prebuilt/dist](https://github.com/paperjs/paper.js/tree/prebuilt/dist) branch
* Check out the latest version from the [develop](https://github.com/paperjs/paper.js/tree/develop) branch and build it yourself, following the instructions in the [README](https://github.com/paperjs/paper.js/blob/develop/README.md) file.
