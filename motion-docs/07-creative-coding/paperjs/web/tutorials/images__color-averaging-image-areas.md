# Color Averaging Image Areas

Paper.js allows you to find the average color of an area within a raster. This allows you to find the average color within a [Rectangle](https://paperjs.org/reference/rectangle), [Point](https://paperjs.org/reference/point) or [PathItem](https://paperjs.org/reference/pathitem) over an image.
