# Getting Started

## [What is swup?](https://swup.js.org/getting-started/#what-is-swup)

Swup is a versatile and extensible **page transition library** for server-rendered websites.
It manages the complete page load lifecycle and smoothly animates between the current and next
page. In addition, it offers many other quality-of-life improvements like **caching**, **smart preloading**,
native **browser history** and enhanced **accessibility**.

Make your site feel like a snappy single-page app — without any of the complexity.

[](/assets/images/swup-demos.mp4)

## [Features](https://swup.js.org/getting-started/#features)

* ✏️

  Works out of the box with [minimal markup](https://swup.js.org/getting-started/example/)
* ✨

  Auto-detects [animations](https://swup.js.org/getting-started/how-it-works/#timing) for perfect timing
* 🔗

  Updates URLs and preserves native [browser history](https://swup.js.org/getting-started/how-it-works/#history)
* 🏓

  Manages [scroll position](https://swup.js.org/getting-started/how-it-works/#scrolling) between pages and anchor links
* 🚀

  Uses a [cache](https://swup.js.org/api/cache/) to speed up subsequent page loads
* 📡

  Offers [hooks](https://swup.js.org/hooks/) to customize and extend the page load lifecycle
* 🔌

  Has a powerful [plugin system](https://swup.js.org/plugins/) and many official and third-party plugins
* 🎨

  Provides ready-to-go [themes](https://swup.js.org/themes/) to get started quickly

See [How it works](https://swup.js.org/getting-started/how-it-works/) for an overview of the key concepts.

## [Plugins](https://swup.js.org/getting-started/#plugins)

Swup is small by design. Extended features can be added via [plugins](https://swup.js.org/plugins/):

* Display a [progress bar](https://swup.js.org/plugins/progress-plugin/) while loading
* Enable [smooth scrolling](https://swup.js.org/plugins/scroll-plugin/) between visits
* Update [meta tags and stylesheets](https://swup.js.org/plugins/head-plugin/) after page loads
* Add support for [preloading pages](https://swup.js.org/plugins/preload-plugin/) in the background
* Perform your [animations in JS](https://swup.js.org/plugins/js-plugin/) instead of CSS transitions
* Animate [form submissions](https://swup.js.org/plugins/forms-plugin/)
* Improve [accessibility](https://swup.js.org/plugins/a11y-plugin/) for screen readers
* Get help in [debug mode](https://swup.js.org/plugins/debug-plugin/)

Check out the list of [official plugins](https://swup.js.org/plugins/) and [third-party plugins](https://swup.js.org/third-party-plugins/).
