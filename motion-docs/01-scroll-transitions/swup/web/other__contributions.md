# Contributions

Any contributions are more than welcome.

If you have a question, suggestion, or feature request, feel free to

* [start a discussion](https://github.com/swup/swup/discussions/new)
* [open an issue](https://github.com/swup/swup/issues/new)
* [create a pull request](https://github.com/swup/swup/pulls)

## [Pull Requests](https://swup.js.org/other/contributions/#pull-requests)

If you would like to see a new feature in swup, we encourage you to fork swup and create a [pull request](https://github.com/swup/swup/pulls)!

Please make sure to run the swup tests locally before creating your PR on GitHub:

```
npm install && npm run test
```

```
npm install && npm run test
```

## [Plugins & Themes](https://swup.js.org/other/contributions/#plugins-and-themes)

Creating [plugins](https://swup.js.org/plugins/create-plugin/) and [themes](https://swup.js.org/themes/create-theme/) is encouraged.
You can list your plugin or plugin idea in the [Plugin Ideas](https://github.com/swup/swup/discussions/335) discussion thread.

## [Join Us](https://swup.js.org/other/contributions/#join-us)

If you think you're proficient in the swup ecosystem and you'd like to join the team, please get in touch at [gmarcuk@gmail.com](mailto:gmarcuk@gmail.com?subject=I want to be a swup contributor).
