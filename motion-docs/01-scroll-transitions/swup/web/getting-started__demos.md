# Demos

Looking for a demo of swup animations in action? You are in fact looking at one! These docs are built
with swup and CSS-only animations. See below for more isolated examples showcasing swup's
features and options.

Click the View Source button
of each demo to see the code and fork it for experimenting yourself.

## [Basic animation](https://swup.js.org/getting-started/demos/#basic-animation)

Default swup installation with two containers and a fade animation between pages.

[View Source](https://github.com/swup/demos/tree/main/basic/)

## [Slide animation](https://swup.js.org/getting-started/demos/#slide-animation)

Slide pages into view horizontally.

[View Source](https://github.com/swup/demos/tree/main/slide/)

## [Overlay animation](https://swup.js.org/getting-started/demos/#overlay-animation)

Cover content while loading the new page.

[View Source](https://github.com/swup/demos/tree/main/overlay/)

## [Multiple animations](https://swup.js.org/getting-started/demos/#multiple-animations)

Use swup's animation classes for other elements than the main content containers.

[View Source](https://github.com/swup/demos/tree/main/multiple/)

## [Slideshow animation](https://swup.js.org/getting-started/demos/#slideshow-animation)

Animate between pages as a horizontal slideshow. Uses the [Parallel Plugin](https://swup.js.org/plugins/parallel-plugin/) to show both pages at the same time
and the [Preload Plugin](https://swup.js.org/plugins/preload-plugin/) to preload the slides.

[View Source](https://github.com/swup/demos/tree/main/slideshow/)

## [Reveal animation](https://swup.js.org/getting-started/demos/#reveal-animation)

Reveal the next page using masks and gradients.
Uses the [Parallel Plugin](https://swup.js.org/plugins/parallel-plugin/) to show both pages at the same time.

[View Source](https://github.com/swup/demos/tree/main/reveal/)

## [Fragment support: modal](https://swup.js.org/getting-started/demos/#fragment-support-modal)

Load sub-pages as modals.
Uses the [Fragment Plugin](https://swup.js.org/plugins/fragment-plugin/) to dynamically select containers based on route.

[View Source](https://github.com/swup/demos/tree/main/fragment-modal/)

## [Fragment support: list](https://swup.js.org/getting-started/demos/#fragment-support-list)

Uses the [Fragment Plugin](https://swup.js.org/plugins/fragment-plugin/) to replace only the items of a list when applying filters.

[View Source](https://github.com/swup/demos/tree/main/fragment-list/)

## [Animated forms](https://swup.js.org/getting-started/demos/#animated-forms)

Animate form submissions using the [Forms Plugin](https://swup.js.org/plugins/forms-plugin/).

[View Source](https://github.com/swup/demos/tree/main/forms/)

## [Inline forms](https://swup.js.org/getting-started/demos/#inline-forms)

Submit simple forms in place without full page loads using the [Forms Plugin](https://swup.js.org/plugins/forms-plugin/).

[View Source](https://github.com/swup/demos/tree/main/inline-forms/)

## [Infinite scroll cache](https://swup.js.org/getting-started/demos/#infinite-scroll-cache)

Persist items loaded with infinite scroll between page visits.

[View Source](https://github.com/swup/demos/tree/main/infinite-scroll-cache/)
