CSS Vars for split words & chars!
(items, grids, images, too!)

Splitting creates elements and adds CSS variables to unlock amazing possibilities for animating text, grids, and more!

[Get Splitting →](https://splitting.js.org/guide.html)

Install with `npm i splitting -s` or [Download .zip](https://github.com/shshaw/Splitting/archive/master.zip)
