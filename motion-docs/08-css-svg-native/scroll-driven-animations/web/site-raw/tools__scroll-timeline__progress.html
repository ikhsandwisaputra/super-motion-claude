About this tool

This tool is part of https://scroll-driven-animations.style/ and should help you get a grasp of how a Scroll Timeline Progress works.

Shown in the scroller a single value that represents the scroll progress. It is read directly from the attached Scroll Timeline animation: animation.currentTime.value

⚠️ Your browser does not support Scroll-Linked Animations so these demos will not work. Please use Chrome 115 or newer.
