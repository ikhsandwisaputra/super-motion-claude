# Pricing

Choose the plan that works best for you.

## Compare Plans

| Feature | Free | Legend |
| --- | --- | --- |
| Price | $0 | $168/year or $20 billed monthly |
| Effects | Access to all 75+ effects | Everything in Free |
| Publishes | Up to 8 publishes with Unicorn branding | Unlimited publishes without logo watermark |
| Commercial use | Personal and non-commercial use | Commercial license |
| Exports | Image exports and limited video exports | JSON export, high-quality video exports, and hosting |
| Assets | Standard assets | Custom 3D models and fonts |
| Organization | Basic project management | Folders, versioning, and automatic backups |
| Unicorn Agent | 50 free credits to try it | 200 monthly AI credits |
| [MCP](https://www.unicorn.studio/docs/mcp/) | 200 agent changes a month | Unlimited agent changes |

## AI Credits

Legend subscribers receive 200 AI credits each month to use with [Unicorn Agent](https://www.unicorn.studio/docs/ai/), and Free plan users can claim 50 free credits to try it. Each request is charged for the work it does, up to 30 credits per run, and requests that fail are refunded. Optional one-time credit boosts are available when you need more. See [Credits](https://www.unicorn.studio/docs/ai/#credits) for details.
