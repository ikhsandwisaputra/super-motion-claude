# Unicorn Studio

> A visual design tool for creating production-ready interactive graphics with shaders, media, 3D, and interactive motion.

Unicorn Studio gives designers a spatial, layer-based canvas for combining shader effects, images, text, video, shapes, and 3D models with motion and interaction. Projects can become live website experiences, programmable components, videos, or reusable asset generators.

## Key Product Facts

- Spatial, layer-based canvas built for movement, depth, lighting, distortion, and interaction.
- Shader AI Agent that specializes in creating and editing effects
- 75+ configurable WebGL effects with AI-assisted effect creation and editing.
- Images, shapes, text, video, and 3D models can be combined with motion and interaction.
- Variables, presets, and events make scenes adaptable and programmable.
- Publish live embeds and reusable tools, or export images, videos, and JSON scene data.
- Lightweight production runtime of approximately 40 KB gzipped.
- Free plan includes access to all 75+ effects, up to 8 publishes with Unicorn branding, and 200 MCP agent changes a month.
- Legend is $168/year or $20 billed monthly and includes unlimited publishes without logo watermark, a commercial license, JSON export, high-quality video exports and hosting, custom 3D models and fonts, CDN and asset optimization, folders, versioning, automatic backups, Unicorn Agent with 200 monthly AI credits, and unlimited MCP agent changes.
