# Welcome to Unicorn Studio

## Overview

Unicorn Studio is a visual design tool for creating production-ready interactive graphics with shaders, media, 3D, and interactive motion.

It gives you a powerful, intuitive spatial canvas built for movement, depth, lighting, distortion, and interaction. Combine shader effects, images, text, video, shapes, and 3D models, then design how they animate and respond without having to build the underlying WebGL system yourself.

Start with one of 75+ configurable effects, build something new with Unicorn Agent, or layer multiple techniques together to create a visual language of your own. Everything remains editable, so you can explore freely and refine the result with the precision of a deterministic design tool.

Once a scene is working, it can become more than a single effect. Expose controls for colors, imagery, motion, content, and other properties to turn it into a reusable system — a live website experience, a programmable component, a video, or an asset generator your team can use.

Unicorn Studio is built on more than five years of helping designers bring WebGL into production, combining a capable editor with a lightweight runtime and [Unicorn Agent](https://www.unicorn.studio/docs/ai/), an AI agent built into the editor that creates, edits, animates, and publishes scenes from a prompt.

* **Create** — Design in a spatial, layer-based canvas with 75+ effects, or describe what you want and let Unicorn Agent build it
* **Combine** — Bring together images, shapes, text, video, and 3D models with motion and interaction built in
* **Control** — Use variables, presets, and events to make scenes adaptable and programmable
* **Ship** — Publish live embeds, reusable tools, images, and videos on a lightweight production runtime (~50 KB gzipped)

Unicorn Studio works best in Chrome. It works in other browsers but may not perform as well. Your device must support WebGL2, and hardware acceleration must be enabled in your browser.
