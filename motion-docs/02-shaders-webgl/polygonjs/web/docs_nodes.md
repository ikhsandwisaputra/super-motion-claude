# Node reference

Generated from the engine, so it always describes the release you can download.
257 of 492 node types are documented so far, and the rest are
listed with their names and categories while their documentation is written.

[code](https://polygonjs.com/docs/nodes/code)

Building blocks compiled into CPU and GPU code, used inside builder nodes.

140 node types, 49 documented

[compute](https://polygonjs.com/docs/nodes/compute)

Compute shaders, run on the GPU.

9 node types, 3 documented

[geo](https://polygonjs.com/docs/nodes/geo)

Build and modify objects: primitives, transforms, copies, groups, physics, CAD.

265 node types, 163 documented

[mat](https://polygonjs.com/docs/nodes/mat)

Materials for the objects the geometry nodes make.

22 node types, 15 documented

[render](https://polygonjs.com/docs/nodes/render)

Post-processing effects, applied to the rendered frame.

24 node types, 1 documented

[tex](https://polygonjs.com/docs/nodes/tex)

Generate and process textures.

32 node types, 26 documented
